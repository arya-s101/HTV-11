# Background music

Drop one audio file here named **`theme`** with any of these extensions (checked in this order):

- `theme.mp3`
- `theme.ogg`
- `theme.m4a`
- `theme.wav`

The game picks it up automatically after a page refresh. No code changes are needed.

- It loops quietly (30% volume). Browsers block autoplay, so it starts on the player's first click or keypress.
- A ♪ button appears in the navbar to turn music on or off, and the choice is remembered on that device.
- If no file is here, the button stays hidden and the game runs silently.

The repo must be public for the hackathon, so only use music you have the rights to share: your own track, a CC0 or
royalty-free track (keep its licence and credit), or something you've licensed for this.
